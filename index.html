이 ZIP에는 수정 스크립트, Termux 서버, 원본 백업과 모의 검사가 들어 있습니다. 실제 폰에 설치하거나 실제 계정으로 AI를 호출한 결과물은 아닙니다. 아래 순서로 설치한 뒤 처음에는 짧은 대화 한 건으로 확인하세요.

이미 연결한 위시 서버가 있어도 괜찮아요

이번 서버는 첨부한 공통 연결 자료에서 재구성한 별도 서버입니다. 이미 설치한 위시 서버 파일·인증 파일을 바꾸거나 가져오지 않습니다. 두 서버를 모두 쓸 경우 각각 Termux 세션이 필요합니다.

항목이번 이그나이터 서버
기본 포트17447
설치 폴더~/chasm-gpt-subscription-bridge
본인 계정·연결 코드·작업 기록~/.chasm-gpt-subscription-bridge
실행 명령bash ~/chasm-gpt-subscription-bridge/start.sh
연결 API 확인값/api/status의 api_contract: gpt-subscription-jobs-v1

기존 위시/HAP 서버의 주소가 같은 형식이라고 해서 호환되는 것은 아닙니다. 이번 수정본은 위의 작업 API 확인값을 검사합니다. 확인되지 않는 기존 서버를 주소만 바꿔 연결하지 말고, 이 ZIP의 서버를 별도로 설치하세요.

1. ZIP 저장하기

chasm-gpt-kit-1.6.6.3.zip을 휴대폰의 기본 Download/다운로드 폴더에 저장하세요. 파일명 뒤에 (1)이 붙었다면 아래 명령의 파일명도 실제 이름과 같게 바꿔야 합니다. 가능하면 파일 앱에서 위의 정확한 이름으로 바꾸세요.

2. Termux에서 새 세션 열기

위시 서버가 이미 돌아가면 그 세션은 그대로 두세요. Termux의 화면 왼쪽 가장자리에서 오른쪽으로 밀기 → NEW SESSION으로 새 세션을 엽니다.

이후 명령은 한 줄 붙여넣기 → 엔터 → 작업이 끝나면 다음 줄 순서입니다. 설치를 계속할지 [Y/n]으로 물으면 y와 엔터를 누릅니다. 다른 질문이나 오류가 나오면 그 상태에서 멈추세요.

필요한 도구를 준비합니다. 이전에 설치했어도 이 명령은 설치 상태를 확인합니다.

pkg install nodejs-lts unzip

다운로드 폴더 접근 권한을 연결합니다. 이미 허용했다면 생략할 수 있습니다.

termux-setup-storage

Android 권한 요청이 뜨면 다운로드 폴더를 읽을 수 있도록 허용합니다.

3. 압축 풀고 설치하기

다음을 붙여넣고 엔터를 누르세요.

unzip ~/storage/downloads/chasm-gpt-kit-1.6.6.3.zip -d ~

압축 풀기가 끝나 $가 다시 나타나면 다음 명령을 실행합니다.

bash ~/chasm-gpt-kit/install-termux.sh

설치가 끝나면 서버가 실행되고 다음 형식의 관리 화면 주소가 나옵니다.

http://127.0.0.1:17447/#pair=본인폰에서생성된비밀값

이 예시의 한글을 직접 입력하지 마세요. 내 Termux에 실제로 나온 주소 전체를 길게 눌러 선택·복사하고, Tampermonkey가 설치된 같은 폰의 브라우저 주소창에 붙여넣어 엽니다. #pair= 뒷부분을 빼면 연결되지 않습니다.

서버 실행 중에는 $가 다시 나오지 않는 것이 정상입니다. Termux 세션을 닫거나 Ctrl+C를 누르면 서버가 멈춥니다.

이미 설치 폴더가 있다는 안내가 나오면 재설치로 덮어쓰지 마세요. 아래의 재실행 명령을 사용합니다.

4. 본인 ChatGPT 구독 승인하기

  1. 관리 화면에서 Continue with ChatGPT를 누릅니다.
  2. OpenAI 로그인·승인 화면에서 본인의 계정과 워크스페이스를 선택하고 구독 사용을 승인합니다.
  3. 돌아온 관리 화면에서 사용 가능한 모델 확인을 누릅니다.
  4. 확장 프로그램용 연결 주소 복사를 누릅니다.

로그인·상태 조회·모델 조회는 AI 작업을 만들지 않습니다. 모델 목록이 보이는 것만으로 특정 모델의 실제 호출 성공까지 확인된 것은 아닙니다. 계정·워크스페이스·지역·모델 권한이 맞아야 합니다. 권한 거절을 우회하거나 다른 결제 수단으로 자동 전환하지 않습니다.

이번 서버는 별도 앱 등록이므로 기존 위시에서 로그인했어도 여기서 본인 계정 승인이 한 번 더 필요할 수 있습니다. 기존 위시의 토큰 파일을 복사하지 마세요.

5. 수정 스크립트 설치하기

먼저 Tampermonkey에서 기존 이그나이터 소스와 필요한 설정을 백업하세요. ZIP의 original/chasm-ignitor-1.6.6.2.txt에도 첨부 원본과 같은 내용이 들어 있습니다.

  1. 이번 서버 관리 화면의 4. 이그나이터 수정본 설치 → 이그나이터 GPT 구독 수정본 설치 열기를 누릅니다.
  2. Tampermonkey 설치/업데이트 화면이 열리면 버전 1.6.6.3인지 확인하고 기존 이그나이터를 대체합니다.
  3. 대시보드에서 이그나이터는 하나만 켠 상태인지 확인합니다. 이름을 바꿔 별도로 저장했던 원본·복사본이 있다면 끕니다.
  4. 열려 있던 Crack 탭들을 새로고침합니다. 예전 코드가 남은 탭을 그대로 두지 마세요.

설치 화면 대신 코드가 보이면 Tampermonkey의 유틸리티 → URL에서 설치 기능에 아래 주소를 입력할 수 있습니다. 메뉴 표기는 브라우저·관리자 버전에 따라 다를 수 있습니다.

http://127.0.0.1:17447/chasm-ignitor-gpt.user.js

그 기능도 없다면 ZIP의 chasm-ignitor-gpt-1.6.6.3.user.js를 텍스트 편집기로 열어 전체 복사하고, Tampermonkey에서 기존 이그나이터 편집 → 기존 코드 전체 선택 → 붙여넣기 → 저장으로 대체합니다. 다른 파일의 코드나 examples/tampermonkey-client.js만 설치하면 안 됩니다.

6. 이그나이터에서 연결하기

  1. Crack 채팅방에서 이그나이터 → API 설정을 엽니다.
  2. 새로 추가된 ChatGPT 구독 영역의 연결 주소 칸에 관리 화면에서 복사한 주소 전체를 붙여넣습니다.
  3. 연결·모델 목록 확인 (AI 요청 없음)을 누릅니다. 로컬 연결 권한을 묻는다면 127.0.0.1 연결을 허용합니다.
  4. 표시된 계정 모델을 선택합니다. 추론 강도는 처음에는 모델 기본값으로 두세요.
  5. GPT 구독 설정 저장·사용을 누릅니다.
  6. 이그나이터 메인 화면으로 돌아가 모델 제공자가 ChatGPT 구독, 사용 모델이 선택한 모델인지 확인합니다.
  7. 요약할 대화 범위와 기존 프롬프트를 고른 뒤 시작하기를 한 번 누릅니다.
  8. 완료 결과를 읽고 필요하면 기존처럼 수정하세요. 전송하기를 누를 때 채팅방·원문·메시지 ID·첨부 페르소나·유저노트를 다시 확인합니다.

완료 결과가 표시됐다고 원문이 바로 바뀌지는 않습니다. 원본처럼 사용자가 전송 버튼을 눌러야 최신 AI 메시지 하단에 요약이 붙습니다. 응답 생성·리롤·대화 수정·방 이동은 작업 중 피하세요. 결과가 오래된 원문에 속하면 보관만 하고 적용을 중단합니다.

Google Gemini와 Firebase 제공자도 남아 있습니다. GPT 구독을 쓰려면 위의 ChatGPT 구독 제공자를 선택해야 합니다. Gemini API 키 칸에 연결 코드나 구독 토큰을 넣지 마세요.

7. 다음에 다시 켤 때

휴대폰을 재시작했거나 Termux 서버가 종료됐다면 새 세션에서 다음 한 줄을 실행하세요.

bash ~/chasm-gpt-subscription-bridge/start.sh

설치 ZIP을 다시 풀 필요는 없습니다. 계정·연결 코드를 지우지 않았다면 같은 주소를 계속 씁니다. Termux에 백그라운드 실행을 허용하고 배터리 절전으로 서버가 종료되는지 확인하세요.

종료는 실행 중인 세션에서 Termux의 CTRL → C입니다. 기본 포트가 사용 중이라면 기존 이그나이터 서버가 켜졌는지 먼저 확인합니다. 새 서버가 필요한 경우에만 다음처럼 다른 포트로 실행하고 새로 나온 주소를 저장하세요.

GPT_BRIDGE_PORT=17448 bash ~/chasm-gpt-subscription-bridge/start.sh

같은 인증·작업 폴더를 두 프로세스가 동시에 사용하면 중단합니다. 서버 잠금 파일을 임의로 삭제하지 마세요. 정상 종료 뒤에도 문제가 있다면 비밀값을 가린 오류 문구를 확인해야 합니다.

시간 초과·새로고침·연타가 있었다면

API 설정 → GPT 요청 확인·결과 복원 (GET 조회만)을 누르세요. 기존 요청을 만든 채팅방에서 확인해야 합니다. 조회는 새 AI 호출을 만들지 않습니다.

  • queued, running: 서버가 처리 중입니다. 잠시 뒤 같은 버튼으로 다시 조회합니다.
  • completed: 저장된 완성 결과를 복원합니다. 같은 입력으로 다시 시작해도 기존 요청 번호를 조회합니다.
  • error, INTERRUPTED, REFUSAL, NOT_COMPLETED: 부분 결과를 적용하지 않습니다. 원래 요청은 자동으로 다시 보내지 않습니다.
  • NOT_FOUND/404: 이전 POST가 실패했다고 확정할 수 없습니다. 같은 번호로 조회만 하며 새 번호로 자동 재전송하지 않습니다.
  • blocked_budget: 관리 화면에서 로컬 횟수 설정을 확인합니다. 실제 호출 전 차단된 작업에 한해서 관리 화면에서 같은 번호를 재개할 수 있습니다.

정말 새 AI 호출이 필요하다면 먼저 기존 결과·원문·관리 화면 작업 상태를 확인하고 기존 요청 보관 후 새 요청 허용을 누릅니다. 경고에 동의해도 즉시 호출하지는 않습니다. 다음 시작하기를 눌렀을 때 새 번호를 만듭니다. 이전 작업이 계속 실행 중이면 둘 다 사용량을 소모할 수 있습니다.

전송 단계의 네트워크 오류도 중복 요약을 붙이지 않도록 막습니다. applying 상태가 남았다면 원문에서 실제 반영 여부부터 확인하세요. 결과 버튼을 반복해서 눌러 다시 PATCH하지 않습니다.

이름과 namespace를 유지하는 이유

이 수정본은 기존 스크립트를 대체하는 업데이트입니다. 파일명과 설명, 표시 버전은 바꾸되 아래 식별자는 첨부 원본 그대로 유지했습니다.

항목정책
@name🔷 Chasm Ignitor (Community Logfix) 그대로
@namespacehttps://github.com/jun1-ui/Chasm-ignitor-logfix 그대로
@version1.6.6.3
@updateURL, @downloadURLnone; 원본 배포처의 자동 업데이트로 수정 코드가 덮이지 않도록 설정
기존 설정chasm-ignt-settings 그대로
기존 프롬프트 DBchasm-ignitor 그대로
새 연결 주소·요청 기록Tampermonkey의 전용 GM 저장소

같은 이름·namespace를 유지해 관리자에서 기존 항목을 대체하도록 한 정책입니다. 설치 화면에서 새 항목이 별도로 생기면 기존 항목을 꺼서 하나만 실행하세요. 수정본끼리는 문서 실행 표식으로 중복 초기화를 막으며, 프레임 실행도 끕니다. 다른 이름·namespace로 설치된 수정하지 않은 원본의 코드를 이 수정본이 강제로 멈출 수는 없으므로 그 복사본은 직접 꺼야 합니다.

되돌리려면 이번 수정본을 끄고 원본 백업을 기존 항목에 복원하세요. 원문·프롬프트 DB를 지우는 동작은 포함하지 않았습니다. 본인 계정 연결까지 해제하려면 관리 화면의 계정 연결 해제 및 ChatGPT의 앱 사용량·접근 설정을 이용하세요.

비밀값과 데이터 보관

  • #pair=… 주소는 이 설치를 제어하는 비밀값입니다. 본인 수정 스크립트에만 넣습니다. 캡처·상담·공유 시 가리세요.
  • OpenAI access/refresh/ID 토큰은 Termux의 보호 파일에만 저장됩니다. 스크립트·API 키 칸·브라우저 저장소로 전달하지 않습니다.
  • 사이트 로그인은 기존 코드의 정상 로그인 정보를 기존 사이트 API에 사용하는 방식 그대로입니다. 그 로그인 정보를 OpenAI로 보내지 않습니다.
  • AI 입력에는 선택한 대화와 원래 설정으로 첨부한 페르소나·유저노트가 포함됩니다.
  • 작업 원문·완료 답·수정 답은 복원을 위해 본인 폰에 남습니다. 서버의 jobs/, account.json, identity.json, registration.json과 Tampermonkey의 GM 기록은 배포 파일에 넣지 마세요.
  • 브리지의 로컬 횟수 제한은 공식 구독 잔여량이 아닙니다. 실제 요청은 구독 한도를 소모합니다. ChatGPT 설정의 사용량을 확인하세요.

확인된 것과 아직 확인하지 않은 것
